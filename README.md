# Sekolah Karir — Role Explorer

A simple web page for exploring job roles. Role information is loaded from a JSON file and displayed as cards that can be filtered by department.

## Features

- Displays job title, department, employment type, and description
- Filters roles by departments
- Empty State Handling
- Uses a responsive card grid

## Project files

- `index.html` — page structure and department filter 
- `style.css` — page and role-card styles
- `index.js` — loads the role data, renders cards, and applies filters
- `role.json` — role data
